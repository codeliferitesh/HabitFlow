HabitFlow | Titanium V1.0  A premium, dark-mode habit tracker built for performance. Features:  Analytics: Matplotlib donut/line charts.  UI: Fluid animations &amp; DPI-aware.  System: Thread-safe notifications &amp; SQLite.  By Ritesh ❤️
🚀 HabitFlow | Titanium V1.0
HabitFlow is a premium, dark-mode habit tracker built with Python and Tkinter. Designed for high-performance individuals, it combines minimalist aesthetics with deep data analytics.

✨ Key Features
Titanium Dashboard: Smooth slide-up animations and real-time "Sparkle" feedback for daily wins.

Advanced Analytics: Visualizes progress via Matplotlib donut and line charts.

Native Notifications: Thread-safe Windows alerts (WNDPROC-stable).

Persistence: Local-first SQLite database for total privacy.

High-DPI Support: Crisp, sharp UI on 4K and 1080p displays.

🛠️ Quick Setup
Clone the repo:

Bash

git clone https://github.com/YOUR_USERNAME/HabitFlow-Titanium.git
Install dependencies:

Bash

pip install -r requirements.txt
Run the app:

Bash

python habitflow.py
🧠 Tech Stack
Language: Python 3.8+

GUI: Tkinter (Customized)

Database: SQLite3

Data Viz: Matplotlib
